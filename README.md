## ✨ Features

- **4,800 questions** across 24 categories — 12 Music + 12 Movie
- **Single Player mode** — sign in and compete on the Worldwide Leaderboard
- **MultiPlayer hot-seat mode** — 2 to 10 players, one device, zero repeats between players
- **Guest play** — jump straight in with no sign-up required
- **Worldwide Leaderboard** — cumulative scores tracked across all sessions
- **Countdown timer** per question with difficulty-based point values
- **Fully self-contained** — single HTML file, no server required, works offline

## 🚀 How to Run Locally

No server needed. Just open the file:

```bash
# Clone the repo
git clone https://github.com/HDMultiMedia/MusicMovieTrivia.com.git
cd MusicMovieTrivia.com

# Open in your browser
open index.html          # macOS
start index.html         # Windows
xdg-open index.html      # Linux
```

---

## 🌐 GitHub Pages Deployment

This site is deployed via **GitHub Pages** from the `main` branch root.

To enable GitHub Pages on your fork:
1. Go to **Settings → Pages**
2. Set Source to **Deploy from a branch**
3. Choose **main** branch, **/ (root)** folder
4. Click **Save** — your site will be live at `https://username.github.io/MusicMovieTrivia.com`
